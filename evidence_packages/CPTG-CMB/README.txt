CPTG CMB Comparison-Map Closure Paper - Release Candidate v1.0
==============================================================

This package contains the release-candidate manuscript and reproducibility materials for the CPTG CMB comparison-map closure paper.

Primary manuscript files:
- CPTG_CMB_Comparison_Map_Closure.tex
- CPTG_CMB_Comparison_Map_Closure.pdf

Support files:- data/ CSV result tables and run metadata
- figures/ manuscript figures
- scripts/ analysis scripts used for map-space testing
- renders/ rendered page previews from the final PDF audit
- render_contact_sheet.png

Scope boundary:
This paper focuses on real-map CMB comparison-map closure using Planck and WMAP temperature-map products. TT/TE/EE spectrum-space closure, lowE, lensing, and full likelihood-grade Planck validation are reserved for separate work and are not part of the primary claim chain in this manuscript.

External data boundary:
Large Planck and WMAP survey FITS files are not redistributed in this package. Reproduction requires downloading the CMB products listed in the manuscript tables and placing them in the local working directory before running the command ledger.
